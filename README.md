# OW + AOW Fun Dive Refresh

本项目是一个本地静态网页，用来在出国 fun dive 前复习 OW/AOW 知识、英文潜水简报和装备检查。

## 打开方式

直接用浏览器打开 `index.html` 即可，不需要启动服务器。

## 文件结构

- `index.html`：页面内容、复习卡片、英文场景、词汇表、装备清单和参考资料
- `styles.css`：响应式页面样式
- `app.js`：中英切换与装备清单本地勾选保存
- `assets/diving-refresher-hero.png`：页面首屏视觉图
- `assets/signals/`：从本地 GUE 水下沟通资料中抽取的关键手势参考图
- `assets/gear-check-annotated-base.png`：BCD + 气瓶 + 调节器无人装备标注底图
- `assets/gear-check-photo.png`：早期真人穿着参考图，页面已不再引用
- `assets/finning-frog-kick-photo.png`：水下踢法真实风格参考图
- `assets/underwater-signals.svg`、`assets/gear-check-diagram.svg`、`assets/fin-kicks.svg`：早期抽象图示，页面已不再引用
- `research/`：本次整理用的资料抽取文本
- `research-notes.md`：资料来源、重点参考和内容边界

## 后续扩展方向

- 潜水日志：地点、深度、时间、水温、配重、气耗和复盘
- 潜水计算器：SAC/RMV、MOD、Nitrox、配重趋势
- 目的地笔记：潜点、季节、水温、流况、潜店和装备建议
- 英语听力：把 briefing 句子做成可播放的练习卡片

## 安全说明

这份网页只用于复习，不替代正式 refresher 课程、潜店简报、潜水电脑、训练机构标准或医疗建议。
